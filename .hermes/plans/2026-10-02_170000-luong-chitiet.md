# Kế hoạch chi tiết: Bảng lương tự động (tháng 9 thử, tháng 10 chạy)

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Cuối tháng máy tự làm sẵn bảng lương khớp cách tính tay tháng 9, bạn chỉ gõ vài ô tay.

**Architecture:** Thêm 3 sheet mới (GIÁ LƯƠNG, LƯƠNG TAY, LƯƠNG KÈM) + hàm tính lương trong Code.gs + 1 tab "Lương" trong BaoCao.html. Giá tiền ghi 1 lần dùng cả năm; mỗi tháng máy đọc CHECK IN ra ngày công rồi tính sẵn, bạn gõ bổ sung rồi bấm xuất.

**Tech Stack:** Google Apps Script (Code.gs), SpreadsheetApp, BaoCao.html (google.script.run), giữ nguyên công thức 70% cứng + 30% thưởng của bảng cũ.

## 0. Chốt với bạn (đã đủ, khỏi hỏi lại)

- Bậc 1 buổi: Học việc 80k, B1 100k, B2 120k, B3 150k, B4 180k, B5 200k, B6 220k, B7 250k.
- Full: 1 lớp/tháng = giá 1 buổi x 8 (8 hay 10 buổi vẫn vậy). Part: đếm buổi thật x giá 1 buổi.
- Dạy kèm giá riêng từng lớp; buổi tăng giờ tính theo giờ (VD Chí Khôi 100k/1.5 tiếng, học 2 tiếng = 150k).
- Kiêm nhiệm: Tuấn Ngọc +5tr, Uyên Vi +5tr. Tháng 9 Nhung = 2 buổi x 120k + 3.5 giờ VP x 42k = 387k. Tháng 10 trở đi Nhung = VP 2.35tr + 2–3 lớp.
- BHXH trừ 10.5% trên tiền đóng (đa số 5.1tr, Uyên Vi 10tr).
- Thưởng: tự đánh giá 30% + quản lý 70% = điểm chung; mốc >=85% hưởng 100%, 70–84% hưởng 75%, 50–69% hưởng 50%, dưới 50% = 0.
- Xăng xe 0đ (bỏ cột). Tháng 9 không truy thu/truy lĩnh.
- Full: Tuấn Ngọc (NV0101), Uyên Vi (NV2301), Vân Anh (NV0204), Đức Anh (NV2707), Khánh Vân (NV0904). Part: Bảo Trâm (NV2412), Hạnh Nhung (NV2503), Chí Khôi (NV0801), Tuyết Quỳnh (chưa có mã — cần bạn cho mã).
- Hồng Anh (NV1308) tính đủ hết tháng 10, từ tháng 11 bỏ ra.
- Tháng 9 làm thử so tay, khớp rồi tháng 10 chạy tự động.

**Còn thiếu 1 mã:** Tuyết Quỳnh để trống (part không ổn định, khi nào có mới báo).

**Ngày công chuẩn:** nghỉ cố định thứ 3 hàng tuần → tháng 9 = 26, tháng 10 = 27 (tháng 10 có 4 ngày thứ 3).
**Tháng 10 Nhung:** 1 lớp (tăng thì báo sau).
**Quy ước phép (đã chốt):** ngày thường nghỉ không tính phép; nghỉ T7/CN = 1 ngày phép + trừ tiền buổi đó; tiền thuê dạy thay ghi riêng 1 dòng, trung tâm chịu.

Hàm đọc giá (viết 1 lần, dùng chung):

```js
function giaLuong() {
  var sh = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('GIA_LUONG');
  var g = { bac: {}, cheDo: {}, bacNV: {}, kiemNhiem: {}, bhxhMuc: {}, mocThuong: [] };
  if (!sh || sh.getLastRow() < 2) return g;
  var v = sh.getDataRange().getValues();
  for (var i = 1; i < v.length; i++) {
    var loai = String(v[i][0]).trim(), ma = String(v[i][1]).trim(), val = v[i][2];
    if (loai === 'BAC') g.bac[ma === 'HOCVIEC' ? 0 : Number(ma)] = Number(val);
    else if (loai === 'CHE_DO') g.cheDo[ma] = String(val);
    else if (loai === 'BAC_NV') g.bacNV[ma] = Number(val);
    else if (loai === 'KIEM_NHIEM') g.kiemNhiem[ma] = Number(val);
    else if (loai === 'BHXH_MUC') g.bhxhMuc[ma] = Number(val);
    else if (loai === 'MOC_THUONG') g.mocThuong.push({ moc: Number(ma), tyLe: Number(val) });
  }
  g.mocThuong.sort(function (a, b) { return b.moc - a.moc; });
  return g;
}
```

## 3. Hàm tính lương 1 người

**File:** Code.gs — thêm sau `getBaoCaoThangTatCa` (dòng ~643).

```js
function getLuong1Nguoi(ma, thangStr) {
  var g = giaLuong();
  var bc = getBaoCaoThang(ma, thangStr);          // ngày công, tổng giờ, trễ
  var tay = docLuongTay(ma, thangStr);            // số lớp, phép, điểm, tiền VP
  var cheDo = g.cheDo[ma] || 'Fulltime';
  var giaBuoi = g.bac[g.bacNV[ma]] || 0;
  // Tiền lớp
  var tienLop = (cheDo === 'Fulltime')
    ? giaBuoi * 8 * (tay.soLop || 0)
    : giaBuoi * (tay.soBuoi || 0);
  // Lương cứng có chấm công: tienLop*0.7 / chuẩn * (thật + phép)
  var luongCung = tienLop * 0.7;
  var mauSo = tay.chuan || 26;
  var luongThang = mauSo ? (luongCung / mauSo * ((bc.ngayCong || 0) + (tay.phep || 0))) : 0;
  // Part không chấm ngày công theo chuẩn thì lấy thẳng
  if (cheDo !== 'Fulltime' && !(bc.ngayCong > 0)) luongThang = tienLop * 0.7;
  // Kèm + kiêm nhiệm (Nhung tháng 9 = công thức riêng)
  var tienKem = tongLuongKem(ma, thangStr);
  var kiemNhiem = g.kiemNhiem[ma] || 0;
  if (ma === 'NV2503' && thangStr === '09/2026') {
    kiemNhiem = (tay.soBuoi || 0) * 120000 + (tay.gioVP || 0) * 42000; // = 387k
  } else if (ma === 'NV2503' && (tay.tienVP || 0)) {
    kiemNhiem = tay.tienVP; // tháng 10 trở đi: 2.35tr
  }
  // Thưởng theo mốc điểm
  var mucThuong = tienLop * 0.3, diem = tay.diem || 0, tyLe = 0;
  var mocs = g.mocThuong.length ? g.mocThuong : [{ moc: 85, tyLe: 1 }, { moc: 70, tyLe: 0.75 }, { moc: 50, tyLe: 0.5 }];
  for (var i = 0; i < mocs.length; i++) { if (diem * 100 >= mocs[i].moc || diem >= mocs[i].moc) { tyLe = mocs[i].tyLe; break; } }
  var tienThuong = mucThuong * tyLe;
  var tong = luongThang + kiemNhiem + tienKem + tienThuong;
  var mucBH = (g.bhxhMuc[ma] || g.bhxhMuc['MAC_DINH'] || 5100000);
  var truBH = Math.round(mucBH * 0.105);
  return { ma: ma, cheDo: cheDo, tienLop: tienLop, luongThang: Math.round(luongThang),
    kiemNhiem: kiemNhiem, tienKem: tienKem, tienThuong: Math.round(tienThuong),
    tong: Math.round(tong), truBH: truBH, thucNhan: Math.round(tong - truBH),
    ngayCong: bc.ngayCong || 0, tongGio: bc.tongGio || 0, diem: diem };
}
```

Ghi chú cho người làm:
- `bc.ngayCong`: số ngày khác nhau có dòng IN trong tháng (đếm từ CHECK IN, dùng `ngayCuaO` đã có).
- `docLuongTay`, `tongLuongKem`: đọc 2 sheet mới theo `ma + thangStr`, thiếu thì trả 0.
- Điểm `diem` nhập dạng 0–1 (VD 0.95) hoặc 0–100 đều được (code chịu cả 2).
- Người nghỉ (NGHI_TU): `getBangLuongTatCa` bỏ qua từ tháng nghỉ (Hồng Anh từ 11/2026).
